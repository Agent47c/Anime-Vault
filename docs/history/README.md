# Implementation history

This directory preserves earlier implementation reports, investigations and
screen-by-screen UI notes. Their original names and content are retained, with
local Markdown links adjusted for the move.

Reports describe the code at the time they were written. Earlier claims such as
test counts, installer hashes and completed fixes are historical evidence, not a
guarantee about today's working tree. Use the current [changelog](../../CHANGELOG.md),
[documentation index](../README.md) and [latest code review](../maintenance/CODEBASE_REVIEW_2026-11-14.md)
for the current state.
